# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability in the Agent Passport System Rust crate, please report it responsibly.

**Report privately:** https://github.com/aeoess/agent-passport-rust/security/advisories
**Email:** security@aeoess.com
**Response time:** We aim to acknowledge within 48 hours and provide a fix timeline within 7 days.

**Please include:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

**Please do NOT:**
- Open a public GitHub issue for security vulnerabilities
- Exploit the vulnerability beyond what is needed to demonstrate it
- Share the vulnerability publicly before we've had time to address it

## Supported Versions

| Package | Supported |
|---------|-----------|
| agent-passport-system >= 0.3.0 | ✅ |
| Older versions | ❌ |

The only earlier published release, 0.2.0 on crates.io, is unsupported; the
advisory for 0.3.0, GHSA-5p55-qp29-p3qc, published at
https://github.com/aeoess/agent-passport-rust/security/advisories, describes the
verification defects it carries.
